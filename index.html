Why is there a difference?
Row-major traversal benefits from spatial locality. When a memory address is accessed, the CPU loads the surrounding data into its fast cache. Since Python lists of lists store row elements sequentially, subsequent accesses are lightning fast.

Column-major traversal skips around memory, causing frequent cache misses and forcing the CPU to fetch data from slower RAM.
